
# AQUORA — Product Landing Page

AQUORA is a modern and responsive landing page concept for a reusable water bottle brand. The website is designed to showcase product benefits, awards, and available shopping platforms through a clean, elegant, and user-friendly interface.

## Project Overview

This project was developed as part of the application assignment for the **Frontend Developer position at Gradin Surabaya**. It demonstrates my ability to build a product landing page using fundamental frontend technologies, structure web content, and create a responsive user interface.

## Features

- **Hero Section** — Introduces the AQUORA brand with a prominent headline and product presentation.
- **Product Benefits** — Highlights the key advantages of the reusable water bottles.
- **Awards Section** — Showcases product awards and recognition.
- **Shopping Platforms** — Provides links to available shopping platforms, including Tokopedia, Shopee, and TikTok Shop.
- **Contact Section** — Displays contact information for inquiries.
- **Responsive Layout** — Adapts the website layout to different screen sizes.
- **Navigation Bar** — Provides convenient navigation between website sections.

## Tech Stack

- **HTML5** — Structures the website content.
- **CSS3** — Handles styling, layout, colors, and responsive design.
- **Google Fonts** — Uses DM Sans and Manrope for typography.

## Design Concept

The AQUORA landing page uses a nature-inspired color palette to create a clean, modern, and premium brand identity.

- Forest Green: `#203D32`
- Moss Green: `#526B50`
- Cream: `#F8F6EF`
- Sand: `#E9E3D5`
- Orange Accent: `#D98253`

The design focuses on readability, visual hierarchy, product presentation, and ease of navigation.

## Project Purpose

This project was created to fulfill the frontend development application assignment for **Gradin Surabaya**. Through this project, I aimed to demonstrate my understanding of HTML, CSS, Bootstrap, responsive web design, and the implementation of a landing page based on a given brief.

## Getting Started

To run the project locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/aquora-landing-page.git
   ```

2. Navigate to the project folder:
   ```bash
   cd aquora-landing-page
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code for local development.
